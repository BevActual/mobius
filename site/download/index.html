Download Mobius

Free and open source, for Windows 10 and 11. macOS is on the way.

Download for Windows

The button opens the latest release on GitHub. Download the file that ends in x64-setup.exe. See what's new in each release.

An AIA plan you already pay for (ChatGPT, Claude or GitHub Copilot), an API key, or a model that runs on your own computer.

Install it

  1. Download Mobius_<version>_x64-setup.exe from the latest release.
  2. Open it. Mobius installs and adds itself to the Start menu.
  3. Open Mobius and pick the AI you want it to use.

If Windows says "Windows protected your PC"

Mobius's installers are signed through Microsoft, but Windows can still warn about an app it hasn't seen often. Choose More info, check that the file came from the Mobius releases page on GitHub, then choose Run anyway.

Updates

Mobius checks for a new version shortly after it starts and then every four hours. When one is ready, the toolbar shows Update available · Restart to install. Updates are signed, and Mobius only installs an update whose signature matches the key built into it.

Uninstall

In Windows, open Settings › Apps › Installed apps, find Mobius and choose Uninstall. The uninstaller asks whether to delete your Mobius data as well. Leave it unticked to keep your notes, documents and settings for a later reinstall.
