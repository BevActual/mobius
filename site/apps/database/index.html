Database

Browse and query databases, with or without SQL.

Make a database or import a CSV file or a sheet, and each table opens ready to browse. Sort, filter and edit rows much like a spreadsheet, or switch to SQL when you want it.

What you can do

  • Three views

    Every table opens with Data for its rows, Structure for its columns and SQL for any statement.

  • Browse without SQL

    Sort by any column, filter rows by the words they hold and page through a hundred rows at a time.

  • Edit in place

    Change a cell by double-clicking it, add rows, and undo your last change.

  • Query history

    Bring back an earlier query and copy any result as CSV.

  • Bring in your data

    Import a CSV file or a sheet from Sheets as a table.

  • Safe questions

    Mobius reads through a read-only connection, so a query it writes cannot change anything.

With MobiusMobius answers questions about your data with charts and tables through a read-only connection, and any change to the data asks first and waits for your Keep or Discard.

Where it's keptEach database is a SQLite file in your workspace.
