Apps/Assistant

Store

Add apps, skills and connectors when you need them.

Store is where you add to Mobius: more apps, skills that teach it steps, and connectors that give it new tools. Start small and add more as you go, since apps load only the first time you open them.

What you can do

  • Apps as cards

    Browse apps grouped by what they are for, each with one line on what it does and Add or Open.

  • Remove without losing files

    Removing an app takes it off your menus but keeps its files, and Undo puts it straight back.

  • Skills you can shape

    A skill is a short, named set of steps: edit them one by one, see earlier versions or run it.

  • Look before you install

    Before a shared skill is added you see what it is for, its steps and what it says it will use.

  • Add connectors

    Add Model Context Protocol servers by command or address, and see at a glance which ones are running.

  • Start up stays quick

    Apps load the first time you open them, so adding more does not slow Mobius down when it starts.

With MobiusMobius can propose a new skill, which waits dashed for your Keep like any other change.

Where it's keptEach skill is a SKILL.md file, and connectors are listed in an mcp.json file in Mobius's data folder.
