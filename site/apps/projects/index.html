Projects

A place for one piece of work.

A project gathers its conversations, files and memory on one page, with its own rules for what Mobius may do. A line at the top says what it has made, what waits on you and when it last moved.

What you can do

  • Rules per project

    Choose Ask each time, Review changes or Auto for each app; paying, sending, deleting and running commands always ask.

  • Project threads

    Move conversations in and the project's rules apply; take one out and the conversation is kept.

  • Project memory

    Each project has its own memory page, and what Mobius proposes for it waits dashed until kept.

  • Files in one list

    See the project's folder and everything its threads made or changed, newest first.

  • Ask a bot

    Send one of your agents off on a side job, and its report comes back into the thread.

  • Nothing lost on delete

    Deleting a project keeps its threads, folder and memory page; only the project and its rules go.

With MobiusMobius works within the project's rules, and what it proposes for the project's memory waits dashed until you keep it.

Where it's keptEach project has its own folder in Files and its own memory page in Knowledge.
