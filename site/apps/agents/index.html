Apps/Assistant

Agents

Named helpers for the jobs you repeat.

Give an agent a name, instructions and a model, then run it when you ask or on a schedule. Each agent's page shows what it does, when it runs and how its recent runs went.

What you can do

  • Run on a schedule

    Start an agent on weekdays or every day at a set time, and still run it whenever you ask.

  • One page per agent

    See its instructions, model, schedule, what it can use and its recent runs in one place.

  • Clear run status

    Each run says where it stands: a question for you, working, finished or failed.

  • From a chat

    Turn a conversation into an agent: its name comes from the title and its instructions from your first ask.

  • Same safety rules

    An agent works under the same permissions as Mobius, and its card says exactly what it may touch.

  • Help inside projects

    In a project, Ask a bot sends an agent off on a side job, and its report comes back into the thread.

With MobiusEach agent works like Mobius with its own instructions and model, and its finished runs wait for you to review.
