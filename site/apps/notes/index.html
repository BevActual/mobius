Notes

Quick pages, saved as you type.

Write and your page is formatted as you go, with headings, checklists, tables and pictures. Notebooks, pins and tags keep everything easy to find.

What you can do

  • Formatted as you write

    Headings, lists, checklists you tick, tables, pictures and links between notes, with nothing to set up.

  • Record a meeting

    Notes listens for up to three hours and writes the transcript into the page; only the words are kept, never the sound.

  • Summarise and make tasks

    After a meeting, Mobius writes a summary and the actions into the note and adds each action to Tasks.

  • Tags and pins

    Every #tag you write builds a Tags list, and pinned pages stay at the top.

  • Version history

    Compare an earlier version with the page now and restore it, and even that can be undone.

  • Share a page

    Copy a page, export it as a web page or Markdown, or print it.

With MobiusSelect text for Mobius's actions right where it is, then keep or discard its edits, line by line if you like; it never overwrites a page while you type.

Where it's keptEach page is a Markdown file in your workspace, in a folder for its notebook, so it opens in any editor.
