Sheets

Spreadsheets with formulas, saved as plain files.

Type in a cell or the formula bar, and formulas work across sheets with a hint for the function you are in. Columns size themselves, and headers and totals are spotted for you.

What you can do

  • Formulas across sheets

    Use functions like SUM and IF and refer to cells on other sheets, with hints as you type.

  • Smart headers and totals

    A first row of words reads as a header, and a last row that adds up the rest reads as the total.

  • Number formats

    Show a column as Number, Currency or Percentage, following your computer's region.

  • Sorting that stays tidy

    Sort by any column while the header and total rows stay where they are.

  • Find in a sheet

    Matching cells are tinted, and you can step from one to the next.

  • Analyse mode

    Ask about your numbers and get charts and tables back, with no cell ever changed.

With MobiusIn Analyse mode Mobius answers with charts and tables and never changes a cell, and the Mobius panel shows the sum, average and count of the cells you pick.

Where it's keptEach workbook is a folder in your workspace, with each sheet a CSV file that any spreadsheet app can open.
