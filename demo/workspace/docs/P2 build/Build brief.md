# Build brief

So basically the P2 build runs the week of the 23rd at Northfield and what we are trying to do, at a high level, is get the second prototype, which is the P2, running on the sled by the Friday of that week, with the battery packs fitted and also the motor tested at full load, which we have never actually done on a full vehicle before, so it is quite a big deal for the programme overall.

## Goal

Two running Kestrel P2 chassis on the sled by Friday, packs fitted and the motor tested at full load. Also we want to get some data on thermal behaviour if there is time but that is more of a nice to have and probably will not happen, to be honest.

## Packs

Eight 60 kWh packs from Veltro, six weeks from order. The deposit has to be paid by Friday or the slot goes. There was some talk of Ardent as a second source, which might be cheaper but is a week slower and we have not tested their cells, so for now it is Veltro, although that could change if the price moves, which it might.

## Motor

The Axion 150 kW, with the controller on firmware 2.4. Sam runs the bench test on Wednesday. If the bench run slips again, the whole test order needs re-planning, and that would push the crash test, which pushes everything else.

Packs late. Bench run slips. Weather at Northfield (the sled is outside). Budget: the packs alone are most of it.
