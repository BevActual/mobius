# Glossary

Mobius's own words, defined once. Pages link here instead of explaining them again.

| Term | Meaning |
| --- | --- |
| **Abilities** | The app where you add apps, skills, connectors and plugins. See [Abilities](guide/abilities.md). |
| **Agent** | The app that opens on the desk and holds your conversations with Mobius. |
| **Agents** | Named helpers with their own instructions and model, for jobs you repeat. See [Agents](apps/assistant.md#agents). |
| **Apply changes** | The permission where Mobius's changes go in at once, and Undo takes them back. See [permissions](guide/working-with-mobius.md#permission). |
| **Ask each time** | The permission where Mobius asks before every step. |
| **Auto** | The permission where Mobius runs on its own in the apps you switched on, checking each step with your quick model first. |
| **Checkpoint** | A snapshot of your workspace taken before Mobius changes anything, which is what makes Discard and Rewind possible. |
| **Connector** | An MCP server that gives Mobius more tools. See [Connectors](guide/abilities.md#connectors-mcp). |
| **Core** | The part of Mobius that decides what may happen and keeps the record. It runs as its own process. See [Architecture](developers/architecture.md). |
| **Dashed** | How a change from Mobius is drawn until you keep or discard it. |
| **Desk** | The Agent app's home: what waits for you, what Mobius is doing, recent conversations, and what's next. |
| **Discard** | Put things back as they were before Mobius's change. |
| **Floor** | An action that is asked about every time, whatever the permission: running a command, deleting files, reading a secret, clicking or typing on a web page. |
| **Gateway** | A connection to a model service: a plan you sign in to, an API key, or a server. See [Gateways](guide/models-and-gateways.md#gateways). |
| **How I work** | Your private page in Knowledge: what Mobius remembers about you. |
| **Keep** | Accept Mobius's change; the dashed edge goes. |
| **Knowledge** | The app with what Mobius knows: How I work and shared pages such as project memory. |
| **Little Mobius** | The conversation in a small window that stays above other apps (Ctrl+Shift+M). |
| **Mobius** | The app, and the agent inside it. |
| **Mode** | The kind of help you want, chosen in the message box: Agent, Ask or Plan. See [Mode](guide/working-with-mobius.md#mode). |
| **Needs you** | A step that is waiting for your answer or approval. |
| **Permission** | How much Mobius does without asking, chosen in the message box. See [permissions](guide/working-with-mobius.md#permission). |
| **Profile** | A separate set of conversations, files, memory and settings, such as work and personal. |
| **Project** | A place for one piece of work, with its own rules, threads, memory and files. See [Projects](apps/write-and-plan.md#projects). |
| **Quick model** | The model for small jobs, such as checking steps under the Auto permission. |
| **Review changes** | The default permission: Mobius changes your files without asking, and every change waits, dashed, for you to keep. |
| **Rewind to here** | Put every app back as it was after an earlier turn. See [Rewind](guide/working-with-mobius.md#rewind-to-here). |
| **Second model** | The model asked when the first is busy or down. |
| **Skill** | A named set of steps Mobius follows when you ask, kept as a `SKILL.md` file. |
| **Try another** | Discard Mobius's change and ask it to do the job a different way. |
| **Turn** | One request to Mobius and everything it did to answer it. |
| **Workspace** | The folder where every app keeps its files, inside the data folder. |
