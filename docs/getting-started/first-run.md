# Your first run

The first time Mobius opens, it asks two things: how much it should do on its own, and which model it should use.

## 1. How much should Mobius do?

Pick a permission. You can change it later from the message box or in **Settings › Approvals and safety**.

| Permission | In short |
| --- | --- |
| **Ask each time** | Mobius asks before every step. |
| **Review changes** (recommended) | Mobius changes your notes, documents, tasks and other files without asking, and every change waits for you to **Keep**, **Discard** or **Try another**. Browsing, mail and commands still ask. |
| **Apply changes** | Like Review changes, but changes go in at once and **Undo** takes them back. |
| **Auto** | Mobius does the work and checks each step first with your model. Anything risky or unclear stops and waits for you. |

Whatever you pick, paying, sending, deleting and running commands ask you each time. See
[Working with Mobius](../guide/working-with-mobius.md) for the details.

## 2. Choose a model

Mobius works with the AI you choose. The quickest options:

- **Sign in to a plan you already pay for.** Your ChatGPT plan, or your Claude Pro or Max plan through Claude Code.
- **Paste an API key** from OpenAI, Anthropic, Google Gemini, OpenRouter, Mistral, Groq and others.
- **Run a model on this computer.** Mobius can install the engine, pick a model that fits your graphics card, download
  it and start it in one step. Nothing leaves your computer.

All three are covered in [Models and gateways](../guide/models-and-gateways.md).

## 3. Say hello

Once a model is connected you land on the **desk**, Mobius's Home. Type what you want in the message box.
A few things to try:

- "Make a task list for moving house next month."
- "Draft an email to Sam asking to move Thursday's meeting." (The draft waits in Mail for you to send.)
- "Turn my note on the Kestrel build into a document with an outline."

What Mobius changes shows up in the app with a dashed edge until you keep it.

## Start with fewer apps

A new install starts with the everyday apps: Notes, Tasks, Calendar, Mail, Docs and Browser, plus Mobius's own apps
(Home, Agents, Activity, Abilities, Settings, Projects, Files, Review and Views). Add the rest, such as Sheets, Slides, Music or Code, from
[Abilities](../guide/abilities.md) when you want them.
