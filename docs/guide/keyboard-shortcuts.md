# Keyboard shortcuts

Change any of these in **Settings › Keyboard**: click a shortcut's key field and press the new keys (Esc cancels).
The small x clears a shortcut, and **Reset** puts back the usual keys.

| Keys | What it does |
| --- | --- |
| Ctrl+K | Find apps, pages and commands (the launcher) |
| Ctrl+, | Open Settings |
| Ctrl+\ | Show two apps side by side, or one |
| Ctrl+Shift+M | Open or close Little Mobius |
| Ctrl+Space (hold) | Dictate in the message box; release to stop |
| Shift+Tab (in the message box) | Switch mode: Ask first, Propose, Act |
| Ctrl+L | Go to the address bar (Browser) |
| Ctrl+T | Open a new tab (Browser) |
| Ctrl+W | Close the current tab (Browser) |
| Ctrl+F | Find on the page |
| C | Comment mode: comment on anything in the app |
| Esc | Stop reading a reply aloud; close a menu or dialog |

**Quick entry from anywhere** brings Mobius up and starts a message even when Mobius is in the background. It has no
key until you set one.

Each app also has its own keys, listed in its menus. A few worth knowing:

- **Slides, while playing:** arrows, Space or a click go on; B blacks the screen; P shows the presenter view; Esc stops.
- **Design:** V, F, R, O and T pick the move, frame, rectangle, oval and text tools.
- **Code:** Ctrl+/ comments lines, Ctrl+G goes to a line, Tab and Shift+Tab indent.
